# Mona Mayhem Product Brief

## Product vision

Mona Mayhem is a retro arcade-inspired GitHub contribution battle arena. The app turns GitHub contribution activity into a playful comparison experience where users can pit profiles against each other in a themed, game-like UI.

## Core experience

- Compare two GitHub users or profiles side by side
- Surface contribution patterns in an easy-to-read, game-like dashboard
- Emphasize playful visual feedback and retro styling
- Create a lightweight competitive experience around coding activity

## Primary goals

- Make contribution data more engaging and visually fun
- Highlight differences in activity in a clear, readable way
- Keep the app approachable for casual users and developers alike
- Deliver a polished arcade aesthetic without sacrificing maintainability

## Non-goals

- Complex analytics dashboards beyond the core battle experience
- Heavy abstraction or framework overengineering
- Unnecessary feature bloat that distracts from the game-like experience

## Design principles

- Clean and readable code
- Modular components
- Retro arcade feel with consistent visual language
- Friendly, playful user experience
- Simplicity over cleverness
